# Glossary

_Last reviewed: March 2025_

- **Board**: the whole set of tasks, stored in one JSON file.
- **Column**: a status. A task is in exactly one column at a time.
- **Statuses**: `todo` → `doing` → `complete`. "Open" means anything that isn't complete.
- **Stats**: the summary line `<complete>/<total> done, <open> open`.
